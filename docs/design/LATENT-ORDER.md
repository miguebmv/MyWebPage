# Latent Order

Latent Order treats every dataset as a field of observations whose structure is present before it
is visible. Points begin as uneven, locally clustered fragments. A deterministic seed fixes their
underlying state so apparent randomness remains reproducible and intentional.

The cursor behaves as an analytical lens. Nearby observations settle toward a small family of
signals and reveal plausible relationships. Order is local, temporary and earned through
attention.

Connections appear only where distance and influence support them. This thresholded graph keeps
the field sparse, while restrained noise contributes breathing at rest. The response colour
adapts to its environment: sea-glass teal in the nocturnal theme and warmer coral in daylight.

When attention leaves, observations return gradually to their imperfect positions. Touch devices
and reduced-motion preferences receive a deterministic static composition with the same
conceptual structure.
