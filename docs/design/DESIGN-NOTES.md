# Miguel Bravo portfolio — design direction

## Direction

An editorial, text-led portfolio: restrained enough to feel senior and professional, but not
anonymous. It borrows structural lessons—not visual copies—from strong independent portfolios.

## Visual system

- Compact fixed identity column and a wider scrolling work column on desktop.
- Soft navy dark mode and warm paper light mode; system preference is respected on first visit.
- Manrope carries the narrative; IBM Plex Mono is reserved for dates, labels and technical metadata.
- Sea-glass accents in dark mode and a restrained warm-coral response in light mode.
- Motion is limited to navigation, image crops and subtle interactive fields.

## Information architecture

1. Value proposition
2. About
3. Experience
4. Four selected projects
5. Complete twelve-project archive
6. Speaking and publications
7. Contact

The selected projects establish depth; the archive makes the complete body of work accessible
without giving every item the same visual weight.

## Behaviour

- English or Spanish defaults to browser language, then persists the visitor's choice.
- Colour mode defaults to the operating-system preference, then persists the visitor's choice.
- The layout collapses into a concise identity header below 900px.
- Reduced-motion preferences are respected.
- Language and colour preferences are shared across every page.
- The opening screen uses the seeded “Latent Order” data field.
- The About photograph uses the “Elastic Portrait” interaction on compatible pointers.
- The final section is a neutral contact directory rather than a commercial call to action.

## Deployment requirement

Production must remain fully bilingual, retain a visible language switcher, persist the visitor's
selection, translate interface and accessibility content, and be verified on desktop and mobile.
