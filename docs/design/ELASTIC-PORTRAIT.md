# Elastic Portrait

Elastic Portrait treats a personal photograph as a physical presence rather than a static asset.
The image follows attention through a spring relationship: the pointer defines intent, while the
portrait arrives a fraction later. That separation makes the interaction tactile without turning
a professional portfolio into a toy.

A tuned spring pulls the portrait toward the drag target, damping removes excess energy, and
velocity survives release long enough to communicate weight. Time-normalised integration keeps
the response smooth across refresh rates, while cached boundaries prevent layout work from
interrupting motion.

The frame is a real boundary. Contact reverses velocity and absorbs most of its energy, producing
one restrained rebound instead of perpetual motion. Pointer velocity and the gesture vector are
blended at release so the portrait glides, rebounds and gradually loses energy.

Coarse pointers and reduced-motion preferences resolve the photograph into a stable composition.
Desktop pointers receive the full spring simulation. The behaviour supports the portrait rather
than competing with the work.
